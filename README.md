# project-euler-solutions
My solutions to Project Euler problems. From [Project Euler](https://projecteuler.net/).

## Come back to:
- Problem 12 is slow: Instead of calculating all divisors, count divisors using prime factorization. Introductio in Analysin Infinitorum: Leonhard Euler (1748).
- Problem 14 is slow: Use python caching and recursion. Standard library @functools.cache (Python 3.9+).
